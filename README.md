# Calculadora JavaFX

Calculadora de escritorio hecha con JavaFX (vista en FXML con Scene Builder y controlador en Java).

## Estado
- [x] Diseño de la interfaz
- [ ] Lógica de números y operadores
- [ ] Botones CE, back, %, +/-

## Tecnologías
- Java 25
- JavaFX
- Maven

## Cómo ejecutarlo
Abre el proyecto en IntelliJ y ejecuta `CalculadoraApplication`,
o desde terminal: `./mvnw javafx:run`
